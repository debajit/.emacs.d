Insert the current page into Org

Send a page's title and link to the cursor position in the Org buffer you were editing.

Drag this link onto your browser's bookmarks toolbar:

Insert into Org

  1. Place your cursor in an Org buffer in Emacs.
  2. Switch to the web page you want to link.
  3. Click Insert into Org in your bookmarks toolbar.

On first use, allow your browser to open Emacs Org Protocol. Remember that choice if offered. The link is inserted as an ordinary, undoable edit; save your Org file when you are ready.

If dragging is unavailable, create a bookmark named Insert into Org and paste this as its URL:

javascript:location.href='org-protocol://insert-link?'+new URLSearchParams({url:location.href,title:document.title});void(0);

Emacs must be running with the browser-link configuration. Register the URL handler once on each computer using the setup steps in the configuration README.
